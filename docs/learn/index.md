# 主线课程：七阶段结构

> `learn/` 是主线教程的正式落位目录：按**技术依赖**组织为七个阶段，每阶段一个索引页，每课一个学习目标。课程元数据与状态契约见维护者文档《课程元数据 Schema》（`docs/maintainers/lesson-schema.md`）。

## 七阶段一览

| 阶段                                          | 主题                      | 交付什么                       | 前置    |
| --------------------------------------------- | ------------------------- | ------------------------------ | ------- |
| [01 · 基础与模型交互](/learn/01-foundations/) | LLM API、流式、结构化输出 | 能徒手调通 OpenAI 兼容网关     | TS 基础 |
| [02 · Agent Runtime](/learn/02-runtime/)      | 手写工具循环与工程防御    | 一个 200 行、五道防御的循环    | 01      |
| [03 · Agent 能力层](/learn/03-capabilities/)  | 记忆、RAG、工具加固、MCP  | 带记忆、可检索、可扩展的 Agent | 02      |
| [04 · 编排](/learn/04-orchestration/)         | 多 Agent：拆 · 派 · 跑    | 可运行的多任务编排实验         | 02      |
| [05 · 质量与可靠](/learn/05-quality/)         | 护栏、评估、生产化        | 可重复运行的评估与门禁         | 02–03   |
| [06 · 全栈交付](/learn/06-fullstack/)         | Web 前端、SSE、API        | 可本地启动的完整应用           | 01–05   |
| [07 · 产品案例](/learn/07-applications/)      | 客服等产品线组装          | 可演示的业务案例               | 03–06   |

阶段编号即推荐学习顺序；04（编排）依赖 02 之后即可进入，与 03 可并行。

## 迁移状态（如实说明）

主线正文目前仍在 `guide/`（13 站），正按实施方案 P1-03 逐篇迁入本目录；各阶段索引页中的课程表给出**当前正文位置**。迁移完成前，`guide/` 与本目录的链接互为镜像，不存在两份正文。每课的 `status`（implemented / partial / planned）以课程元数据 Schema 为准，来源与测试证据记录在各课 frontmatter。
