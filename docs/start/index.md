# 从这里开始

> 三分钟回答四个问题：这是一套什么样的教程、你是否是它的读者、按什么顺序学、环境怎么搭。

## 这是一套什么样的教程

**AI Agent 工程教程**：以 TypeScript 为唯一主线，从「会调 LLM API」走到「能组装生产级 Agent 系统」。它不是概念科普，每一步都落在可运行的代码上——手写工具循环、接记忆与 RAG、补安全与评估、做多 Agent 编排，最后交付带 Web 前端的完整应用。

1. **能力主线**：章节按技术依赖排序（先循环、再能力、再编排、再质量、再全栈），不按工具或热点排序
2. **事实与代码一致**：教程描述的每个能力都对应 `agent-app/` 里的真实实现与测试；只有演示价值的功能会如实标注边界，不把计划写成已交付
3. **历史不混入主线**：本站前身是一套 23 周按天课程，已于 2026-11 下线（git 历史可考），不再参与任何导航

## 你是否是它的读者

**适合**：会 JavaScript/TypeScript（函数、类、模块、async/await 能读懂并手写），想进入 AI Agent 工程方向的开发者。

**前置要求**：

| 前置                  | 到什么程度算够                            | 不够去哪补                                                                |
| --------------------- | ----------------------------------------- | ------------------------------------------------------------------------- |
| JavaScript/TypeScript | 能手写 async 函数、理解类型标注           | [TypeScript 官方 Handbook](https://www.typescriptlang.org/docs/handbook/) |
| 命令行与 Node.js      | 会用终端、装过 Node、知道 pnpm/npm 是什么 | Node 官网入门文档                                                         |
| 一台开发机            | 能跑 Node 22 与（可选的）Docker           | —                                                                         |

**不需要**：Python、机器学习背景、任何 AI 应用经验——Agent 相关的一切从零教起。

## 怎么用：三层结构

1. **主线教程**（`learn` 七阶段 12 课）：按顺序读，每站有前置、可运行命令与自测。入口是[第 01 站 · LLM API 与结构化输出](/learn/01-foundations/llm-structured-output)
2. **模块深读**（`reference`）：实现细节、代码走读与设计取舍。主线遇到实现疑问时按站内链接进入，例如[工具循环深读](/reference/01-agent-loop)
3. **产品案例**（`cases`）：把学到的零件组装成完整业务，如[知识库问答](/cases/knowledge-base)、[智能客服](/cases/customer-service)

进度判断以「能跑通、能解释」为准：每站末尾有自测题，配套命令能离线运行的部分不需要任何密钥。
